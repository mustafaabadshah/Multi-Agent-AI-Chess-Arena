# Database Architecture

ChessMind Arena utilizes PostgreSQL via SQLAlchemy ORM with automatic SQLite development fallback.

## Schema Overview

### `games` Table
- `id` (UUID, PK)
- `white_model` (VARCHAR)
- `black_model` (VARCHAR)
- `white_personality` (VARCHAR)
- `black_personality` (VARCHAR)
- `status` (VARCHAR: `waiting`, `running`, `paused`, `completed`, `aborted`, `error`)
- `winner` (VARCHAR: `white`, `black`, `draw`)
- `termination_reason` (VARCHAR)
- `initial_fen` (VARCHAR)
- `current_fen` (VARCHAR)
- `pgn` (TEXT)
- `opening` (VARCHAR)
- `stockfish_depth` (INTEGER)
- `move_delay_ms` (INTEGER)
- `created_at` (TIMESTAMP)
- `completed_at` (TIMESTAMP)

### `moves` Table
- `id` (UUID, PK)
- `game_id` (FK -> `games.id`)
- `ply` (INTEGER)
- `move_number` (INTEGER)
- `color` (VARCHAR: `white`, `black`)
- `model` (VARCHAR)
- `personality` (VARCHAR)
- `fen_before` (VARCHAR)
- `uci_move` (VARCHAR)
- `san_move` (VARCHAR)
- `fen_after` (VARCHAR)
- `decision_summary` (TEXT)
- `confidence` (FLOAT)
- `strategy` (VARCHAR)
- `secondary_strategies` (JSON)
- `risk_level` (VARCHAR)
- `alternatives_json` (JSON)
- `stockfish_eval_before` (FLOAT)
- `stockfish_eval_after` (FLOAT)
- `stockfish_best_move` (VARCHAR)
- `centipawn_loss` (INTEGER)
- `move_quality` (VARCHAR)
- `latency_ms` (INTEGER)
- `input_tokens` (INTEGER)
- `output_tokens` (INTEGER)
- `move_source` (VARCHAR)
- `created_at` (TIMESTAMP)

### `game_analysis` Table
- `id` (UUID, PK)
- `game_id` (FK -> `games.id`, UNIQUE)
- `white_accuracy` (FLOAT)
- `black_accuracy` (FLOAT)
- `white_average_cpl` (FLOAT)
- `black_average_cpl` (FLOAT)
- `white_blunders`, `black_blunders` (INTEGER)
- `white_mistakes`, `black_mistakes` (INTEGER)
- `white_inaccuracies`, `black_inaccuracies` (INTEGER)
- `game_phase_stats` (JSON)
- `strategy_stats` (JSON)
- `style_summary` (JSON)
- `critical_moments` (JSON)
- `summary_report` (TEXT)

### `experiments` Table
- `id` (UUID, PK)
- `name` (VARCHAR)
- `num_games` (INTEGER)
- `games_completed` (INTEGER)
- `status` (VARCHAR)
- `model_a` (VARCHAR)
- `model_b` (VARCHAR)
- `results_json` (JSON)
